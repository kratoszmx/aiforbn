# 下一步研究計劃：BN 隔膜的 AI 配方預測、篩選與驗證

更新：2026-09-27。按見微最新決定執行：**先做 BN 隔膜；先用公開資料；驗證方法由我們自己建立，邊做邊溝通；保留 v18，持續迭代本文件。** 以下按工作依賴排序，不指定幾週完成；每個子步驟都可以作為週報項目。

**研究目標：輸入原料、配比和製備條件，預測可能得到的 BN 隔膜材料及性能，再推薦值得驗證的配方，逐步減少無效試驗。** 是否真的節省實驗次數和成本，要在比較與驗證後回答。

## 步驟 1：完成 BN 隔膜的製備結果與性能預測模型

對應見微提出的「輸入反應物，預測生成物」。在隔膜問題中，輸入還需要配比、分散／塗覆工藝等條件；輸出包括改性後材料或複合隔膜、性能預測、來源依據和不確定性。有明確化學反應的部分做生成物預測；物理混合、分散和塗覆按配方／製程建模。例如已有 BN 複合隔膜研究將其結合方式判斷為物理結合，不能一律寫成新分子的合成。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11596189/)

1. **1.1 搜集公開資料。** 從 BN 隔膜原始論文、補充表格、公開資料庫及有實施例的專利開始，整理配方、製備方法、對照樣品、性能和已報告的失敗結果。先查 BN 塗覆聚丙烯（PP）隔膜，其他 BN 隔膜作獨立資料組；不等合作方提供資料。起始入口如下：
   - [BN／石墨烯塗覆 PP 隔膜研究](https://pubmed.ncbi.nlm.nih.gov/33010580/)：已有相關製備與測試研究的線索；目前核查到摘要，完整配方須取得原文或補充資料後才能入表。
   - [海藻酸鈣纖維／BN 複合隔膜研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11596189/)：可讀全文，作欄位設計及另一基膜體系的資料入口；不直接與 PP 資料混成同一體系。
   - [Open Reaction Database](https://open-reaction-database.org/about)：查找適用的化學改性反應及參考資料格式。它以有機反應為主，是否覆蓋本課題須核查，不能充當現成的 BN 隔膜資料集。
2. **1.2 整理成可追溯資料表。** 記錄來源和表格位置、樣品／批次、BN 形態與粒徑、表面處理、基膜、黏結劑、溶劑、比例及計算基準、混合與塗覆條件、厚度、測試條件、結果和單位。區分設計值與製備後實測值；保留缺失，識別重複引用與同一樣品的重複測量。公開可讀與可重新發布分開記錄。
3. **1.3 定下第一版輸入和目標。** 執行起點先採用「BN 塗覆 PP 電池隔膜」，主指標先查**指定溫度、時間及測量方法下的熱收縮率**，同時收集離子傳輸、電解液潤濕及機械性能作後續約束。這是我們的起始選擇，並非見微已指定的基膜或已取得的資料集。若可比較的定量資料主要支持另一項隔膜指標，就在 BN 隔膜範圍內改選並記錄理由，在模型比較前固定下來。黏度和分散穩定性可作製程子任務，不取代隔膜落點。
4. **1.4 建立大模型的材料結果預測流程。** 先使用可用的既有模型，檢索已整理文獻，按固定格式給出可能的製備結果、涉及的改性反應、參考配方及缺少的條件。涉及反應時，單獨建立「反應物＋條件 → 生成物」資料與評估；普通塗覆不編造反應式。先完成可運行流程，再根據錯誤和資料量決定是否微調。
5. **1.5 接上性能預測。** 用實測標籤建立簡單基線及合適的表格模型，預測主指標，與大模型的檢索和材料描述配合。每次輸出區分「文獻已報告」「模型預測」「缺資料、暫不能判斷」。不能用大模型生成的數字當作實驗標籤。

**本步交付：** 來源清單、資料字典、首版整理資料集、模型輸入輸出規格，以及可重跑的預測示例。週報可寫新增來源、獨立配方數、已整理欄位和已跑通的預測。此步完成代表流程可用，可靠程度由步驟 2 判斷；資料尚不足的預測部分標為未完成，繼續補資料。

## 步驟 2：完成模型比較，找出有效的改進

1. **2.1 留出獨立測試資料。** 同一論文、相同配方、重複測量及同源轉載先歸組，避免同一結果同時用於訓練和測試。測試答案不得進入大模型的檢索材料或提示詞；也記錄公開文獻可能已出現在預訓練資料中的限制。
2. **2.2 比較簡單方法與 AI 方法。** 比較訓練資料的平均值／中位數、相似配方查詢、簡單回歸與所選模型；對大模型比較有無文獻檢索的結果。性能預測報告原單位誤差；材料結果和反應生成物按來源支持、材料／產物識別及條件完整度分開評分，不混成一個「準確率」。
3. **2.3 按錯誤改進。** 檢查錯誤來自單位、缺少製程條件、跨基膜混用、資料過少，還是模型本身；逐項比較加入製程條件、文獻檢索或微調是否有幫助。調參只用訓練側資料，最終測試資料不反覆拿來選模型。
4. **2.4 建立可信範圍。** 報告哪些材料和條件有資料支持、哪些屬於外推，並用獨立資料檢查預測區間是否可靠。資料少時照實報告探索結果與誤差，不承諾固定成功率。

**本步交付：** 模型比較表、按來源分組的測試結果、錯誤案例、可信範圍和改進記錄。判斷模型是否在獨立資料上優於簡單方法；沒有改善也保留結果，據此補資料或改方法。

## 步驟 3：完成 BN 隔膜候選配方的生成與排序

1. **3.1 設定可探索範圍。** 根據公開實例確定 BN 形態／改性方式、添加比例、黏結劑、塗覆及乾燥條件等可調項目，先在有依據的範圍內生成候選。
2. **3.2 生成並篩選配方。** 用大模型檢索相近實例、提出有依據的調整，再用性能模型和必要約束篩選。熱收縮、離子傳輸、厚度、機械性能與成本分開展示；關鍵條件不明的配方標明缺口。
3. **3.3 延續 v18 的排序方法。** 同時考慮目標性能、不確定性、資料支持、新穎性及驗證成本，將候選標為「對照、優先、探索、暫緩」。檢查換一組合理權重或模型後，優先候選是否仍然穩定。
4. **3.4 產出可驗證配方卡。** 每張卡寫明材料、用量基準、製程、預測值與範圍、參考來源、未知項目和建議測試。超出支持範圍時標成探索建議，不能寫成有效配方。

**本步交付：** 候選清單、排序依據、對照樣品和配方卡。數量按資料支持及驗證能力確定，不直接照搬 v18 的晶體候選數量。

## 步驟 4：完成獨立驗證，根據結果迭代模型

1. **4.1 先做可自行完成的公開資料驗證。** 固定模型及候選選擇規則後，用未參與開發的來源回測；與相似配方、簡單模型或隨機選擇比較。若所有資料都已用於開發，就另找新來源，不能把已看過的結果冒充盲測。
2. **4.2 建立計算驗證方法。** 為具體問題選有適用依據的方法，例如材料／界面或傳輸模型，先用已知案例檢查。計算只能支持其實際模擬的性質；原有帶隙模型及未鬆弛晶體原型不能驗證隔膜製程或電池表現。沒有適用模擬時，繼續資料驗證和實驗方案準備。
3. **4.3 自行準備實驗驗證方案。** 從步驟 1 起同步查找校內公共平台或外部測試服務，整理樣品、對照、測試方法、重複測量、設備與報價需求。先形成具體測試包，再就資源和費用溝通；不把等待李老師或實驗同事承諾作為開工條件。
4. **4.4 有測試資源後取得新結果。** 測試前固定配方和評估規則，記錄成功、失敗及偏離條件的情況。先評估原模型，再把新資料加入下一版本，保留版本間比較。
5. **4.5 評估是否減少試驗成本。** 比較達到同一預定性能要求所需的候選測試數；取得實際實驗結果後再核算時間與費用。公開資料回放得到的是節省試驗的估計，不能寫成已實際節省的成本。

**本步交付：** 獨立驗證報告、可交接的測試包、資源與費用清單，以及取得實驗後的實測對照和更新模型。週報分別標明「公開資料回測、計算驗證、實際實驗」進度；前兩項可持續推進，實驗完成須有真正的測試結果。

## 步驟 5：整理研究成果、演示與論文材料

1. **5.1 固定可重現版本。** 整理資料版本、來源、分組方式、模型設定、評估命令及候選生成記錄，讓結果可以重跑。
2. **5.2 建立最小演示。** 展示「輸入原料與條件 → 製備結果／性能預測 → 候選排序 → 證據與驗證狀態」，讓使用者看見建議從何而來。
3. **5.3 整理研究貢獻。** 結合已有研究，檢查條件感知預測、跨文獻泛化、不確定性篩選或減少試驗次數中，哪些已有結果支持；用對照實驗說明各部分是否有效。
4. **5.4 形成技術報告與論文草稿。** 寫清問題、資料、方法、比較、驗證及限制，將尚未驗證的候選與實際觀察分開，依證據決定結論。

**本步交付：** 可重現研究包、演示、技術報告和論文草稿。報告從前面各步持續累積，不等最後才整理。
