# Human Documents

This directory isolates human-readable project material from the agent-native source of truth.

## Categories

- `project_reports/`: Chinese project reports, user-facing notes, and teacher-response notes.
- `research_context/`: background research reports, prompts, and planning context.
- `research_plan/`: proposal drafts, LaTeX/BibTeX sources, rendered PDFs, templates, and archived teacher template material.
- `task_notes/`: human-readable task-direction notes that are useful context but not machine contract files.
- `images/`: tracked images and figures intended for human inspection.

Agent-facing contracts remain in `AGENTS.md`, `.agents/skills/`, `docs/AGENT_MANIFEST.json`, `docs/HANDOFF.md`, `docs/PY_FILES_SUMMARY.md`, and `skills/ai_native_workflow.txt`.
