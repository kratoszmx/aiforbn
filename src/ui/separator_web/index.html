04 / READ THE RECIPE

p-BNNT-PP-0.3 是什麼？

名稱片段意思
ppurified，表示純化處理。
BNNT氮化硼奈米管，是加入隔膜的材料。
PP聚丙烯，這個配方使用的隔膜基材。
0.3BN 載量為每平方厘米 0.3 毫克（0.3 mg/cm²），不是 0.3%。
其他常用縮寫
PVDF
聚偏二氟乙烯；在這些塗層配方中用作黏結劑。
NMP / DMF
製備塗層使用的兩種不同溶劑。
CA
海藻酸鈣。
EC / DMC / EMC
碳酸乙烯酯／碳酸二甲酯／碳酸甲乙酯，液態電解液的溶劑。
LiPF₆
六氟磷酸鋰，液態電解液中的鋰鹽。
