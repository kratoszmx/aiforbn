# AI for Science 合作方試用說明

打開公開網址即可使用，不需要邀請碼。頁面分成性能估算、實驗規劃、配方資料與名稱解讀。請只提供公開或已獲准交給線上研究服務的配方。

1. 在「性能估算」選擇任務。BNNT / PP 隔膜可調純化狀態與載量；海藻酸鈣隔膜可調塗布器間隙；液態電解液可調鋰鹽濃度與 EC / DMC / EMC 比例。按按鈕後會顯示數值、單位和依據的研究。
2. 在「實驗規劃」比較找到 3 個達標配方所需的實驗次數。可切換目標導電率、比較方法，也可填入你們每次實驗的工時，換算對應工作量。
3. 在「試排下一輪」保留或修改已測配方及實測值，取得下一輪的 3 個推薦。初始數值來自文獻，推薦器只使用列在表單裡的已測值。新增結果後可再次推薦。
4. 在「配方資料」切換 BN 配方或液態電解液，按名稱、材料搜尋；展開 BN 配方可看製程與原文段落。資料可下載為 CSV，直接用試算表開啟。
5. 名稱解讀中，p = 純化、BNNT = 氮化硼奈米管、PP = 聚丙烯、0.3 = 0.3 mg/cm² 的 BN 載量。

頁面以「模型估算」和「文獻實測」區分兩類數值。實驗次數比較標示為公開電解液資料回放；所有比較方法可展開查看。全站每 24 小時接受 100 次新分析，查資料和讀取已有結果不佔額度。

目前 BN 表的 20 種配方來自四篇已核對原文研究，是這一輪完成整理的數量；另有 38 種液態電解液配方。後續可繼續增加資料。試用時最有用的回饋是：你們需要預測的性能、實際可提供的輸入，以及哪種推薦確實改變了下一輪實驗安排。
