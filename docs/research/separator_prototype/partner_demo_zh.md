# 合作方試用說明

這個原型把公開文獻、配方參數、模型推測和實測對比放在同一頁，方便核查。它目前只能對很小的 PP／BNNT 範圍做探索性數值預測，尚未證明可以取代實驗。

1. 打開邀請連結。查閱文獻、20 個配方案例和下載 CSV／SQLite 不需要試用碼；調用 Astra 才需要。完整邀請連結會自動填入試用碼。請只輸入公開或已獲准提交給 OpenAI 的配方。
2. 按「① 已知案例」，查看適用範圍，再到「公開配方」核對 `BNNT-PP-0.3` 的 0.71 mS/cm 實測值。展開「核對原文」可看到來源段落。
3. 按「② 留出案例」，到「模型對比」查看固定評測。這筆實測為 0.84 mS/cm，已保留在評測中，沒有放入 Astra 的提示。Astra 預測 0.90，簡單線性回歸預測 0.8967；這一次線性回歸的誤差略小。
4. 按「③ 不支持的輸入」，應顯示暫不支持數值預測。搜尋 `CA@BN-3:1-failure` 可以查看相關製備失敗記錄；其他材料體系不會被強行套入 PP 模型。
5. 要試自己的未知配方，可先返回「① 已知案例」，把 BN 載量改成例如 0.4，再按「請 Astra 做探索性預測」。請把輸出當作待驗證的假說。同一輸入可能返回先前真實調用的快取，頁面會標示；它不是新的實驗結果。

最有用的回饋是：你們能否提供這些輸入、最需要預測哪一個性能，以及多大的誤差仍能幫助安排實驗。現有資料只有同一研究的兩個訓練數值和一個評測數值，尚未量得實驗時間或成本節省。

維護者交付入口：本機 `.runtime/separator/partner_invite.txt` 保存完整邀請連結。不要把試用碼加入 Git；公開網址、有效期及驗證結果見同目錄的 `verification.md`。
